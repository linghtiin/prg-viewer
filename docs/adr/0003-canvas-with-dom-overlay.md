# ADR 0003：Canvas 主渲染 + HTML 浮层

- 状态：已接受
- 日期：2026-10-28

## 背景

需要同时满足：大量节点下的平移/缩放流畅、文本与图片按世界坐标绘制、公式可排版、跟随主题。

候选：

1. 纯 Canvas：性能最好，但公式需要自己栅格化（KaTeX 输出 HTML，无法直接画到 canvas）。
2. 纯 DOM/SVG：排版容易，但上千节点时布局与重排成本高。
3. Canvas + 少量 DOM 浮层。

## 决策

- 文本、图片、分组框、连线用 Canvas 2D 绘制（DPR 感知、视口裁剪、布局缓存）。
- 只有 `LatexNode` 用 HTML 浮层，KaTeX 以 **MathML** 输出渲染，随相机缩放字号。
- `Error`/`Loading`/工具条/侧栏使用普通 DOM。

## 后果

- 画布性能可控，公式清晰且无需打包字体资源；
- 浮层需要每帧同步位置，但公式节点数量通常很少；
- 若 KaTeX 输出异常，回退为源码文本并保持可读。
