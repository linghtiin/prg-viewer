# ADR 0001：v0.1 只读查看器

- 状态：已接受
- 日期：2026-10-28

## 背景

`.prg` 是 ZIP + MessagePack + 序列化引用容器。读取它有明确的公开规范；写回则需要完整复刻
Project Graph 的序列化器、类集合与升级迁移逻辑，任何字段偏差都可能损坏用户文件。

## 决策

v0.1 只做只读查看器：

- 不实现保存、不修改 `.prg`；
- 视图状态（相机、选择）不写入文件，只存插件配置；
- 打开文件前后哈希保持一致，作为验收项。

## 后果

- 风险最低，用户可以放心在 Obsidian 中浏览；
- 编辑需求通过 `prg://` 深链交给 Project Graph；
- 写回能力留给后续版本，需要独立 ADR 与兼容性测试矩阵。
