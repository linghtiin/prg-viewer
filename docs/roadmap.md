# 路线图

方向：先把"读得对、看得清"做扎实，再考虑编辑能力。

0.2.0（2026-11-16）已发布：大纲节点树与可拖拽侧栏布局、阅读状态独立文件、滚轮模式；变更见
[CHANGELOG](../CHANGELOG.md)。

0.3.0（2026-11-22）已发布：大纲树改为「包含 / 连接」两组、嵌套分组框不再被父框遮挡、分组框折叠角标改用
方框与强调色；变更见 [CHANGELOG](../CHANGELOG.md)。

0.4.0（2026-11-22）已发布：插件 id 改为 `project-graph-viewer`、改为桌面端插件（`isDesktopOnly`），发布页
额外提供单文件压缩包；变更见 [CHANGELOG](../CHANGELOG.md)。

0.4.1（2026-11-22）已发布：连线标签改为锚定在绘制曲线的中点，修复弯折连线上标签偏到源节点的问题；变更见
[CHANGELOG](../CHANGELOG.md)。

## 0.5

- `![[file.prg]]` 笔记内嵌预览（复用画布渲染，限制尺寸与交互）
- 文件资源管理器缩略图（用容器内 `thumbnail.png`）
- 更多节点类型：`PenStroke`（涂鸦）、`SvgNode`、`MediaNode`、`ReferenceBlockNode`
- 连线标签按边宽推导字号，贴近官方
- 搜索高亮所有匹配项，而不只是跳转

## 0.6

- 导出当前视图为 PNG / SVG
- 节点详情里的双链跳转到 vault 笔记
- 分组折叠状态跟随作者设置并可临时展开
- 键盘导航：节点间 Tab/方向键移动焦点

## 以后

- 只读 → 可编辑（写回 `.prg`）需要完整序列化器与兼容性测试矩阵，风险高，暂不承诺
- 多页/子画布（`sub/<uuid>/stage.msgpack`）
- 大图性能：增量布局、空间索引（目前视口裁剪已够用）

不在计划内：替代 Project Graph 的编辑能力、云端同步。
