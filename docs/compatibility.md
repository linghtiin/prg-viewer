## 与 Project Graph 的已知差异

| 项                                                                   | 本插件             | 说明                                                    |
| -------------------------------------------------------------------- | ------------------ | ------------------------------------------------------- |
| 编辑能力                                                             | 无                 | 只读；编辑请回 Project Graph                            |
| 连线标签字号                                                         | 固定 20 世界单位   | 上游按边宽推导（默认 32），差异仅在带标签的边上         |
| 多目标连线                                                           | 只画首尾端点       | `MultiTargetUndirectedEdge` 未实现                      |
| `PenStroke`、`SvgNode`、`UrlNode`、`MediaNode`、`ReferenceBlockNode` | 占位框             | 保留位置与类名                                          |
| 分组标题                                                             | 左上角 20px 文本   | 上游 32px；折叠/大标题等视觉状态更丰富                  |
| 折叠分组                                                             | 居中标题尺寸外框   | 折叠尺寸按文字估算（上游用真实测量），隐藏子孙一致      |
| 节点框尺寸                                                           | 依实测文本略微扩宽 | 上游用自身字体测量；系统字体宽 2–8%，扩宽保证文字不越界 |
| 图片 `scale` / `isBackground`                                        | 按碰撞盒拉伸       | 上游对背景图有独立层序                                  |
| LaTeX                                                                | KaTeX MathML       | 上游用 KaTeX HTML；MathML 无字体资源依赖，离线可用      |
| 主题                                                                 | 跟随 Obsidian      | 上游使用自带主题系统                                    |

这些差异都属于表现层，不影响文件读取；解析层保证"所见即文件内容"。

## 版本策略

- PRG major ≤ 2：完整解析。
- PRG major > 2：解析并提示"该文件由更新的 Project Graph 生成，部分内容可能无法显示"。
- 未知节点类：占位 + 单次告警，不阻塞其余节点。
- 扩展包（含 `metadata.extension`）：明确提示"扩展包，非画布"。
